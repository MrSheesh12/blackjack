# Landon’s Casino

Blackjack with a two-spot card-match side bet (Dealer Match / Hand Match).
Static mobile blackjack game (no build, no deps). Run: `python3 -m http.server 8000` then open http://localhost:8000.
Files: index.html, style.css, game.js, manifest.json, sw.js, icon.svg. Payouts are tunable in the PAY constant at the top of game.js.
